# Plan: Add 7 Spanish Word Categories

## Objective

Grow the `/words/[category]/` vocabulary section from 1 category (pronouns, 69
entries) to 8 by adding seven Spanish word categories: **prepositions**,
**numbers**, **interjections**, **conjunctions & connectors**, **adverbs**,
**core verbs (ser/estar/haber/tener)**, and a **corpus-frequency** category
derived from the gloss data already committed for the four books.

Six categories are curated JSON data files. The seventh (`frequency`) is
generated by a new build-time script that counts every token across all four
books and aggregates by lemma using the committed `glosses.json` files.

Adding a category is data-only: the chooser, `/words/[category]/`, the sitemap
and the page JSON-LD are already generic. The only shared code touched is
`astro/src/lib/words.ts` (registry import + array entry).

Corpus data used by the frequency category (all committed):

- `astro/src/data/books/{andanzas,barraca,san-manuel,selva}/glosses.json` —
  object keyed by lowercased surface form →
  `{ word, lemma, pos, ipa, ru, grammar, cefr, modern, false_friend, note }`.
  POS values are coarse: `verb noun adj name adv pron prep other num conj interj art`.
  Coverage: 26,793 entries across the 4 books; `lemma` 100%, `ru` 100%,
  `ipa` all but 1.
- `astro/src/data/books/{id}/tokens/{chapter-slug}.json` — array of
  `{ t, w }` where `w` is the lowercased word form (or matched phrase) and
  `null` for whitespace/punctuation/digits. 41 + 11 + 3 + 8 = 63 token files.

Book directories are `andanzas`, `barraca`, `san-manuel`, `selva`. Iterate
them in `readdirSync` sorted order for determinism.

Script conventions (`astro/scripts/`):

- Plain ESM `.mjs`, Node built-ins only (`node:fs`, `node:path`,
  `node:url`). No new dependencies ever.
- Pure logic in `astro/scripts/lib/*.mjs`, tested by
  `astro/test/*.test.mjs` (see `tokenize.mjs` + `test/tokenize.test.mjs`,
  `gloss-parse.mjs` + `test/gloss-parse.test.mjs`).
- CLI wrapper in `astro/scripts/*.mjs` computes `ROOT` as
  `join(dirname(fileURLToPath(import.meta.url)), "..")` (see
  `astro/scripts/gloss.mjs` lines 1–14).

Design/content conventions (locked by `pronouns.json`; follow exactly):

- **IPA**: broad, seseo/neutral (LatAm-leaning). Slashes are stored **in the
  data** (`"/ʝo/"`) and rendered as-is. Castilian `/θ/` is never used.
- **Example**: exactly one short learner-level sentence per entry, always with
  a Russian translation, rendered as `example: { "es": "...", "ru": "..." }`.
  Use the most common form for multi-form entries.
- **`pos`**: short grammatical abbreviation, same style as `pronouns.json`
  (`"prep."`, `"conj."`, `"adv."`, `"interj."`, `"num. card."`, `"num. ord."`,
  `"v."`, `"loc. prep."`). Not a Russian word.
- **`grammar`** and **`note`**: Russian. `grammar` explains this surface form;
  `note` carries usage/register/voseo/archaism remarks. `null` when not needed.
- **`es` must be unique within its group** (React list key).
