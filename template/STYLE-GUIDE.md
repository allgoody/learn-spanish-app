# Style Guide

Reference table of every UI element and its styles for the standalone template in
`template/` (design language: stone neutrals + amber accent, from the astro/ site).
Generated by the `template-style-audit` skill on 2026-09-05. All rows ➕ injected this
session (stylesheet created from scratch).

## How to use

- This file is the single source of truth for element styling — update it whenever
  styles change.
- Dark theme: all colors are CSS custom properties; `[data-theme="dark"]` on `<html>`
  forces dark, otherwise `prefers-color-scheme` is followed (`:root:not([data-theme="light"])`).
- Preview page: `kitchen-sink.html` (open in a browser; "Toggle dark theme" button).
